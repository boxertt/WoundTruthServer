# 发布边界

仓库里放部署所需的脚本、锁定版本、构建结果，以及 Agent 编排和技能说明。测量计算、SAM2 工人和签名实现留在私有工程，编译后再放进 `bin/`。

## 仓库里各放什么

| 部分 | 仓库里的形态 | 说明 |
|---|---|---|
| Agent 编排 | `agent/app/agent_runtime.py` 源码 | 只读切片。不算尺寸，不验签名 |
| 技能说明 | `agent/publishable/` 与 `agent/skills/` 源码 | 四个候选技能，外加 SAM2 预览工作流 |
| 部署脚本 | `deploy/` 源码 | 只做检查和启动顺序 |
| 网页 | `web/dist/` 构建结果 | 从现网构建拷出，没有 source map，没有 `src/` |
| 临床后端 | `bin/woundtruth-web` | Linux aarch64 可执行文件，旁边是 `woundtruth-web.dist` |
| SAM2 工人 | `bin/sam2-worker` | 单个可执行文件，调用部署时重建的 PyTorch 环境 |
| SAM2 运行时 | `deploy/sam2-requirements.txt` | 检查通过后用这份清单重建，大约 4.7 GB |
| SAM2 权重 | 不进 git | 部署时下载 `facebook/sam2.1-hiera-tiny`，大约 298 MB |
| 本地模型 | 不进 git | 部署时 `ollama pull qwen3.6:35b`，大约 23 GB |
| iOS 与采集端 | 不进这个仓库 | 演示使用部署方自己准备的录像 |

## SAM2 运行时为什么不打包进来

GB10 上现用的虚拟环境是 4.7 GB，拆开是：

| 内容 | 体积 |
|---|---|
| NVIDIA CUDA 13 库 | 2.7 GB |
| torch 2.9.1+cu130 | 980 MB |
| triton 3.5.1 | 563 MB |
| transformers 5.15.1 | 110 MB |

这里没有 WoundTruth 自己的代码。Git 单文件上限 100 MB，Release 单文件上限 2 GB，整包放不进去。部署脚本在环境检查通过后，用 CUDA 13 的官方轮子索引重建同一套版本。

工人程序只带我们自己的采样和筛选，不去把这 4.7 GB 打进可执行文件。

## 不进仓库的东西

- 病历、录像、调试 JSON
- 签名私钥
- `runtime/` 和任何虚拟环境
- `node_modules`
- 坐标对齐、测量推导这类内部文档
- iOS 工程和采集端源码
- 带 source map 的前端
- 内网穿透配置

网页构建结果可以阅读压缩后的界面代码。临床计算在后端可执行文件里，不在这个构建结果里。
