# 创视迹 WoundTruth：让 AI 算力服务于每一次创面观察与诊疗

诺贝尔化学奖得主、DeepMind 联合创始人 Demis Hassabis，将利用人工智能理解生命、推动药物发现、最终帮助人类战胜疾病视为长远使命。他创立的 Isomorphic Labs，也将“有朝一日借助 AI 解决所有疾病”作为愿景。这份愿景让我们看到：人工智能的进步，可以与减轻痛苦、改善人类健康紧密相连。[Isomorphic Labs 官方使命](https://www.isomorphiclabs.com/)

我们认同这样的方向。让 AI 服务医学，既需要探索生命科学的重大突破，也需要走进医生每天面对的具体问题。

**创视迹选择从创面跟踪出发，将非接触式数据采集、定量测量、连续病程记录和本地 AI 辅助连接起来，让每一次观察有依据、每一段变化可追溯、每一个临床决定仍以医生为中心。**

创面管理需要长期、反复地观察。医生需要了解创口有多长、创面有多大、局部凹陷有多深，更需要把这些信息放回患者连续的治疗过程中。然而，传统照片缺少深度信息，手工测量和边界描绘耗时，长期积累的图像与备注也增加了查阅负担。创视迹围绕这些问题，构建了一套从采集端到本地智能工作台的完整流程。

**首先，让创面能够被非接触地采集与测量。**

创面不宜为了测量而反复受到接触和扰动。我们利用 iPhone Pro 系列设备的 LiDAR，以及 RealSense 深度相机，同步采集彩色图像、深度和相机参数；同时结合华硕 NUC，开发了面向创面记录的采集设备，通过扫码关联患者信息，将患者身份与采集资料在源头绑定。

配套管理软件利用深度、相机内参和位姿信息，支持创口长度、创面面积及剖面深度等定量测量。测量依赖明确的空间几何关系，结果能够关联到对应录像和帧，便于医生回看与复核。测量精度仍需通过标准夹具和临床场景分别验证。

**其次，让分散的创面资料形成连续的患者病程。**

创面的意义不仅在于某一时刻的形态，也在于它随时间发生的变化。创视迹在采集时绑定患者，在管理端按采集时间组织图像、测量和备注。医生可以沿时间线查看同一患者的历史资料，记录伤情判断、治疗方案、用药及换药情况，为持续随访提供有组织的依据。

系统区分原始采集证据与后续工作修订。新增备注和测量不会覆盖原始采集件，AI 生成内容也不会被混同为医生最初记录的事实。这使后续查阅能够回答：这份资料来自哪里、何时采集、之后发生了哪些修改。

**第三，让本地 AI 帮助医生阅读长期积累的资料。**

一名患者可能积累大量创面图像、测量和病程记录。医生希望 AI 能帮助整理历史、查找相关信息、解释已有测量，并形成可供审阅的摘要；与此同时，医疗资料的敏感性要求系统认真对待数据使用范围。

创视迹利用 NVIDIA GB10 的本地算力运行模型，由后端在本地组织证据并发起推理，减少向外部模型服务传输敏感资料的需求。患者时间线和看图页面旁常驻 AI 对话，医生在切换页面时可以保留会话与草稿，在查阅资料的同时继续提问。

当医生说“分析当前图像”时，系统核对患者、录像、存储位置和原始帧号，将实际对应的图像纳入本次证据。画面变化期间重新核验发送范围；无法确认帧身份时明确说明原因，不把其他图像悄悄当作当前画面。回答以流式方式呈现，只有正常完成的结果才进入持久会话。

**第四，用分割候选减少边界描绘操作。**

创面面积测量需要确定边界，逐点勾画往往耗时。创视迹利用 GB10 算力运行 SAM2，生成可供医生审阅的分割候选，并将候选区域叠加在主图中，支持点选、比较和进一步修正。

医生确认候选后，系统再结合深度与标定信息完成几何计算，并通过独立确认流程生成正式测量。SAM2 提供的是区域候选，分割分数不代表创面诊断，像素面积也不会被直接当成物理面积。自动化承担重复操作，医生保留对区域选择和结果采纳的决定权。

**Agent 与 Skills 的设计，是连接这些能力的关键。**

创视迹的患者 Agent 围绕医生确认的证据工作：读取患者历史记录、测量、备注和完整性信息，帮助组织病程摘要、解释已有数据、提示记录缺口，并形成待审阅的文书草稿。原生端采用基于 Pi 的 Agent 实践；GB10 Web 端通过可信后端执行证据读取与本地模型调用，按各端实际实现组织工作流程。

我们将专业能力整理为五个技能包，并为每项能力明确输入、输出与使用边界：

| Skill | 专业能力 | 使用边界 |
|---|---|---|
| 完整性核验 `woundtruth-integrity-verify` | 提供采集包完整性与来源信息 | 不把文件完整性当成医学正确性 |
| 测量审阅 `woundtruth-measurement-review` | 读取、整理和解释已有测量 | 不凭普通图像臆造长度、面积或深度 |
| 备注草稿素材 `woundtruth-note-draft` | 提供备注证据与文书整理所需素材 | 不自行采纳、签署或写入临床记录 |
| 记录总览 `woundtruth-record-review` | 按证据计划组合记录、测量、备注和完整性信息 | 不扩大到未经确认的患者或资料范围 |
| SAM2 测量预览 `woundtruth-sam2-measurement-preview` | 支持分割与测量候选的预览流程 | 不代替医生判断和确认 |

技能包参照开放 Agent Skills 规范组织，`version` 写在 `metadata` 里。本仓库不宣称已经通过官方校验或获得 NVIDIA Verified。NVIDIA Skills 同样建立在这一开放规范之上。在通用技能结构之外，我们增加了面向医疗场景的范围约束、版本关联、来源审计和医生审阅流程。[NVIDIA Skills 文档](https://docs.nvidia.com/skills)

这些设计通过软件流程落实：可信后端先限定范围并读取证据，模型在该范围内辅助生成；临床写入由单独的应用流程处理，需要医生明确确认。四个 publishable 技能包目前仍属于 candidate 工程层，适配器复用生产证据工具，生产问答并未动态加载其 manifest。

我们在合成夹具上比较了「追加技能正文」和「不追加」两组回答。两组使用同一份证据、同一个本地模型和同一组参数，差别只有系统提示末尾是否附上该任务绑定的技能正文。测量技能写进量纲规则之后，7B 这条历史记录不再把已保存的长度写成面积；不追加技能正文的一组仍会出现这种错误。这组结果说明的是边界约束是否被遵守，不说明创面尺寸测得更准确。协议、十个任务和合成表见[部署与模型优化说明](03_部署与模型优化说明.md)第 5 节。

创视迹希望探索的，是 AI 在医疗工作中一种具体而负责任的位置：帮助医生减少重复整理，获取更完整的历史依据，更方便地观察创面变化，同时保留临床判断、审阅与确认的主体地位。

**从一次非接触采集，到一条连续病程，再到一次有依据的 AI 辅助，我们希望把本地算力转化为医生能够理解、核对和使用的工具，为更好的患者照护贡献一份切实的力量。**
